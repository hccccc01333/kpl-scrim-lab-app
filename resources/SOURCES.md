# 参考目录来源

采集日期：2026-10-28。目录更新时间与每个主图 SHA-256 记录在 `catalog.json`。

- 英雄名称与标识：[王者荣耀官方英雄目录](https://pvp.qq.com/web201605/js/herolist.json)。
- 装备名称与标识：[王者荣耀官方装备目录](https://pvp.qq.com/web201605/js/item.json)。
- 主头像与装备图片：`game.gtimg.cn/images/yxzj/img201606/` 下对应英雄与装备资源，具体地址保留在目录的 `url` 字段。
- 装备补充图片：`res.edata.qq.com/sgame/static/images/equipment/`，具体地址保留在 `variantSources` 字段。

这些名称、角色形象和装备图片来自官方公开资源，权利归原权利人。本项目将其用于本机候选检索与人工核对，目录不代表官方评级或对本项目的认可。

仓库不再分发这些图片素材。需要时运行 `python scripts/sync_catalog.py` 在本地拉取，
目录文件与主图 SHA-256 会重新写入 `catalog.json`。不拉取也不影响平台使用，
只是跳过图像匹配，手工录入照常工作。

默认英雄头像不覆盖所有皮肤；目录不保证覆盖历史装备、特殊模式或后续更新。下载失败的图标明确记录为空，并允许用户手工输入。

英雄身份读取头像下方名字，不使用默认头像匹配，也不学习人工标注的英雄头像。目录中的英雄图片只用于目录展示。

正式入库的装备裁剪可作为本机辅助检索参照，不会上传到上述资源服务器。样本仍包含在原比赛及本地备份中。归档比赛后，该局装备样本退出检索；恢复入库后才重新参与。相似度不足时保持未知，不以首位候选代替正确答案。
