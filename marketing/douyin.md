# 抖音 · 三条短视频

抖音的规则和另外两个平台完全相反：**前 3 秒没有冲突，后面拍得再好也没人看**。所以三条全部从"具体到有点疼"的场景开场，不讲定位、不讲理念。

竖屏 1080×1920，字幕压在安全区（距底部至少 250px），因为右侧按钮和底部文案会挡。

---

## 视频 1｜痛点版（35 秒，Day 2）

**发布文案**

```text
训练赛打完还要加班抄数据？现在七页截图丢进去就行 #电竞 #KPL #王者荣耀 #电竞教练 #赛训
```

**分镜**

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:04 | 手机拍电脑屏幕：Excel 里一个格子一个格子敲数字，敲错、删掉、重敲 | **训练赛打完，教练组还要加班两小时——就为了把截图里的数字，一个个抄进表格。** |
| 0:04–0:08 | 快速闪：七页截图、录屏、xlsx、营地链接 | 十个人，五个指标，五十个数。 |
| 0:08–0:16 | 屏幕录制：七页截图拖进上传区 → 进度条 → 结果页数字带高亮 | 我做了个工具：截图丢进去，本机识别，数字带着高亮出来。 |
| 0:16–0:22 | 关键镜头：鼠标逐项点确认，高亮消失、卡片变绿；一个越界值被红框拦下 | **你点一下确认，它才入库。错数进不了统计。** |
| 0:22–0:28 | 切四档来源标签特写（文件解码 / 引擎实测 / UI 采样 / 估算） | 每个数字还标着来源。混口径这件事，从根上就避开了。 |
| 0:28–0:33 | 地址栏 `127.0.0.1:8766` + 任务管理器无外连 | 全程不连云，数据就留在你自己电脑里。 |
| 0:33–0:35 | 结尾卡：`covers/douyin-cover-01.png` 的下半部分（产品名 + Windows 10/11） | Windows 装完双击就能用。主页。 |

> 这条的核心是 **0:16 那一刀**：确认后卡片变绿、越界值被拦，是全片唯一的"爽点"。
> 剪的时候把它放慢 0.5 秒，其他部分能多快多快。

## 视频 2｜反常识版（45 秒，Day 7）

**发布文案**

```text
别再用 Excel 管训练赛数据了，三个原因 #电竞教练 #数据分析 #赛训 #KPL #王者荣耀
```

**分镜**

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:04 | 狠狠地关掉一个 Excel 窗口，黑底大字「别再用 Excel 管训练赛」 | **别再用 Excel 管训练赛数据了。三个原因。** |
| 0:04–0:16 | Excel 表里一堆数字，三个不同来源的数混在同一列；叠字「从哪来的？」 | **第一，Excel 不知道这个数是从哪来的。** 截图 OCR 读的、营地面板拿的、回放文件解出来的，可信度完全不同。混在一张表里算平均，等于把误差当结论。 |
| 0:16–0:27 | 两个单元格并排：`31 局 / 51.6%` 和 `3 局 / 66.7%`，长得一样；叠字「样本呢？」 | **第二，Excel 不会告诉你样本多大。** 31 局 51.6% 和 3 局 66.7%，在表里长得一模一样。 |
| 0:27–0:38 | 手打错一位数，表格毫无反应；切到工具，越界值红框拦截 | **第三，Excel 抄错不会报警。** 这个工具里，OCR 结果全是候选值，你确认了才入库；缺字段、类型不对、数值越界，直接拦下来。 |
| 0:38–0:43 | 单局页快速滚一遍（时间线 / 经济曲线 / 掉点） | 数据进来之后，时间线、经济曲线、掉点，一页看完。 |
| 0:43–0:45 | 结尾卡 | Windows 装完就能用。主页。 |

> 「三个原因」是抖音最容易完播的结构。每条原因**只讲一句结论 + 一个画面证据**，不要展开。

## 发布与运营

**节奏**

- 工作日 **12:00–13:00** 或 **19:00–21:00** 发。教练群体午休和晚饭后是活跃高峰。
- 三条之间隔 3–5 天。同一账号短期内连发同类工具内容会被压量。

**标题与封面**

- 发布文案就是标题，前 12 个字最关键，别把"我做了个"放在最前面。
- 封面用 `covers/douyin-cover-01.png`，抖音会裁成 3:4 展示，主标题在画面上半部分，不会被裁掉。

**标签**

```text
#电竞 #KPL #王者荣耀 #电竞教练 #赛训 #数据分析 #效率工具 #独立开发
```

**评论区置顶（三条通用）**

```text
主页简介有官网。
Windows 10 / 11，安装包内置运行时，不用装 Python，不要管理员权限。
个人、教学、非营利免费；俱乐部采购和商业使用需要单独授权，这个先说清楚。
```

**私信自动回复**

```text
你好，KPL 赛训工具的官网和安装包在主页简介里（GitHub Releases）。
装完双击就能用，不用配环境；数据全部在你本机，不连云。
如果安装时被 SmartScreen 拦了，是没做代码签名，选「仍要运行」即可，或者找我要网盘链接。
```

## 三条纪律

1. **不要口播"链接在评论区"**。抖音对站外引流判定很敏感，说"主页"就够了。
2. **不要出现真实战队名、选手 ID、真实比分**，也不要露出营地的手机号、昵称、二维码。演示一律用自带合成数据。
3. **不要说"准确率""自动分析"**。一旦承诺，第一个 OCR 错字就会变成评论区攻击点。把"要你确认"讲成设计，而不是缺陷。
