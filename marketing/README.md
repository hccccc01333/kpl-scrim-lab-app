## 二、必须打透的三个点

| # | 卖点 | 一句话说法 | 为什么它重要 |
|---|---|---|---|
| 1 | **省人工** | 七页截图进去，本机 OCR 出候选值，你确认一下才入库 | 唯一一个教练 10 秒内能听懂的收益 |
| 2 | **数据可信** | 每个数字标来源（文件解码 / 引擎实测 / UI 采样 / 估算），冲突并列显示，不取平均 | 赛训组被"数据对不上"坑过，这是差异化 |
| 3 | **数据不出本机** | 本地起服务，不连云，`data/` 拷走就是完整备份 | 训练赛数据是俱乐部机密，这条决定敢不敢用 |

辅助卖点（按内容取用）：**两条合规路径**（营地面板为主 / 七页截图 + 录屏兜底）、**审核带 `before/after` 审计日志**、营地只留一个月时的老对局补录、安装包 + 增量更新与失败回滚、深色 / 浅色主题。

**不要说的话**：不要说"AI 自动分析""一键出结论""准确率 99%"。这个产品真正的价值是**把事实准备好、把可疑的地方标出来**。一旦承诺自动结论，用户第一次发现 OCR 错一个数就会全盘不信。

## 五、转化路径（别在这里踩坑）

- **小红书**：正文和评论里不要出现完整链接，会限流。主页简介写「KPL 赛训工具｜Windows 免安装｜GitHub: hccccc01333」，正文结尾写"装法放评论区"。
- **B站**：简介可以直接放官网和 Releases，B站对纯工具链接相对宽松；再在置顶评论复述一遍。
- **抖音**：主页简介挂官网，视频里只说"主页"，不要说"链接在评论区"。
- **给赛训组发包**：用微信 / 网盘发 zip，**不要发浏览器下载链接**。经浏览器下载的 exe 会带网络标记并触发 SmartScreen；同时给 `.sha256`。这条写进私信话术，能明显减少"装不上"的抱怨。
- **赞助**：只在 B站简介和官网提，短视频里不提。工具受众对"卖东西"很敏感，先建立信任。

## 六、合规红线（逐条核对）

1. **禁用词**：破解、外挂、透视、读内存、绕过检测、读取客户端。对外只讲**回放解析、界面采样、本地识别**。
2. **不出现真实数据**：一律用自带合成演示数据（`python scripts/seed_demo_data.py`，12 场，队名选手比分全虚构）。不要出现真实战队名、选手 ID、真实比分。
3. **不用官方素材**：KPL / 王者荣耀的 logo、赛事 logo、选手照片一律不用。英雄图标出现在产品截图里属既有界面，不单独做视觉主体。
4. **每处都留边界**：写明「与游戏开发商及赛事组织方无关联，不对数据准确性作绝对保证」。
5. **许可必须讲清楚**：个人 / 教学 / 非营利免费；**俱乐部采购、付费服务、商业集成需单独授权**。这句不写，后面会有一批俱乐部直接商用，很难收。
6. **不承诺准确率**：把"OCR 会出错，所以要你确认"讲成设计，不要藏起来。
