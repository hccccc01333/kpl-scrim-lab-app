## 置顶评论

```text
补几个片子里没展开的：

1. 采集有四种来源：营地链接（扫码授权、增量拉十人面板，不走 OCR）、七页赛后截图（本机 OCR 出候选值）、
```

## 重做素材

```bash
# 1) 起隔离演示实例
$env:KPL_DATA_DIR='...\marketing\video\.demo'; $env:TRAINING_PORT='8791'
python server.py
# 2) 灌合成数据（营地面板会带真实昵称，必须洗）
python scripts/seed_demo_data.py --base http://127.0.0.1:8791 --games 12 --with-camp
python marketing/video/_scrub_names.py
# 3) 抓 24 个二级页面
python marketing/video/capture_modules.py
# 4) 出片
python marketing/video/render_bilibili_promo.py --render
```
