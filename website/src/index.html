在下载之前

三个常被问起的问题。

答案都在安装说明里，这里先给结论。

会把数据传到你们的服务器吗？

不会。没有云端服务，识别、入库、分析都在本机跑；唯一的外部请求，是你自己发起的营地同步与更新检查。

更新会不会覆盖比赛记录？

不会。增量更新只替换程序文件，data、.env 与营地授权都不在更新范围内；失败自动回滚。

需要先装 Python 吗？

不用。安装包内置运行时与全部依赖，双击就能跑；只有源码运行才需要 Python 3.11 / 3.12。
