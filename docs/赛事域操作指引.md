# 赛事域 · 教练操作指引（三步上手）

## 第 0 步：重启工作台（一次性）
代码已更新，8766 主服务需要重启一次才吃到全部新能力。

## 第 1 步：选择赛事（右上角「上手引导」→ 定赛事）
- 点右上角「上手引导」，第一阶段会引导你选择或新建赛事（筹备中 → 开始备战 → 归档）；引导已从首页移除。
- 引导按「定赛事 → 建底稿 → 出结论」三阶段展示，顶部「下一步」直接指向当前该做的事；进度只计 5 个关键步骤，规则可选、语料持续积累，解锁状态以分析页为准。
- 顶栏会常显当前赛事名；所有分析只看当前赛事的数据。
- 老数据（比赛/系列赛）默认未归属：在赛事页「归档区」把对局挂到赛事，或在「存量系列归属」面板逐个归属。

## 第 2 步：采集（备战组 → 采集）
- 老规矩不变：营地同步 / 截图 / 录屏。
- 采集到的局会按赛事的「训练起始 / 训练结束」自动归档（训练日期落在区间内就归）。

## 第 3 步：编组与分析（备战组 → 系列赛编组 / 大场分析 / 跨局分析）
- 编第一个系列并确认后，大场分析解锁（锁卡消失）。
- 跨局分析在当前赛事语料 ≥20 局后解锁（锁卡有进度条）。

## 正赛数据（两个入口）
- **快速登记**：赛事页「录入正赛」弹窗——30 秒登记对手/比分/日期（自动进对手库、归属赛事），细节以后补。
- **完整表格**：管理 →「正式比赛录入」页——逐局 BP/阵容完整录入，进正式统计。
- 快速登记的局会在「正式比赛录入」页标「待补全速记」，转正补全后同一局不会重复。
- **KPL 拉取**：赛事页「拉取 KPL 正赛」——从官方数据拉本队比赛（自动去重、自动对手建档、含 BP 顺序），勾选落库即可。

## 常见问题
- **切赛事后列表是空的？** 因为老数据还没归属到这个赛事——按第 1 步的归属工具操作一次即可。
- **「顺序待核对」是什么？** BP 顺序没填满双方各 5 人时按采集口径标记，不伪造顺序，补全后自动消除。
- **归档的赛事能改吗？** 不能（只读）。在赛事状态里改回「筹备中/进行中」即可重新编辑。
