# 竞品官网拆解：toolknit.com/zh/

抓取日期 2026-11-15，1440×900 / 390×844 两种视口。所有数字来自浏览器计算样式与资源计时，
不是目测。抓取脚本：`.cache/web-audit/knit_*.py`，截图：`.cache/web-audit/knit-shots/`。

## 0. 一句话结论

ToolKnit 不是“页面排得好看”，而是把官网当成**一个可操作的产品界面**在做：

- 固定侧栏 + 本地收藏 + 折叠故事板 + 首访弹窗，构成“可操作层”；
- 26 条环境动画 + 9 种合成音效 + 一套 0.16–0.22s 的过渡，构成“手感层”；
- 分类台账、收藏卡、故事板、截图框、跑马灯五种版式轮换，构成“节奏层”。

我们现在的站是“一张排得不错的宣传单”：有秩序，但没有可操作层、没有状态层、没有环境层。
差距不在颜色，而在**页面里“被设计过的瞬间”的数量**：他们约 30 个，我们约 8 个。

## 1. 骨架

| 项 | ToolKnit | 我们 |
|---|---|---|
| 导航 | 固定左侧栏 236px，常驻，独立于内容滚动 | 顶部 68px 导航，随页面滚走 |
| 栅格 | 页边 48 + 侧栏偏移 314 + 内容 1270 | 单列 1200，页边 40 |
| 移动端 | 侧栏变抽屉（translateX -285.6px）+ 顶栏汉堡 + 悬浮导航 | dialog 抽屉（已做） |
| 页面纵向 | 3654px（不含页脚），5 个区块 | 约 4200px，5 个区块 |
| 区块高度 | 收藏 302 / 分类 1118 / 故事 602 / 桌面 663 / 开始 490 | 首屏 ~600 / 能力 ~700 / 工作流 ~700 / 主权 ~600 / 开发 ~400 |

侧栏不是装饰：语言切换、分组导航、状态卡、快捷入口都在里面。它让“整站”始终有一个
稳定的操作原点，用户在任何位置都知道自己在哪、还能去哪。

## 3. 可操作层（最大差距）

- **本地收藏**：localStorage 存分组；可新建、编辑、切换 tab；文案明确写“收藏组合仅保存在
  当前浏览器”。编辑用原生 `dialog`，Esc/遮罩关闭。
- **首访弹窗**：把“新版首页已准备好”和 Cookie/隐私说明合并成一个对话框，一个按钮
  “找不到，继续”，背景模糊。
- **回到顶部**：初始 `opacity:0; visibility:hidden`，滚动后才出现；图标带两层“拖尾”路径。
- **悬浮操作堆**：右下固定 42px 圆形按钮（声音、收件箱），移动端再加悬浮导航。
- **GitHub stars**：运行时拉取、按语言格式化，并带 `checkedAt` 校验，失败静默不显示假数。

我们目前唯一“可操作”的是复制终端命令。没有收藏、没有首访提示、没有回到顶部、没有悬浮动作。

## 4. 动效

- 26 条 `@keyframes`：吉祥物 sway / nod / blink / typing / feet / spark，织网 weave-silk，
  字形 glyph-*，卡片入场 collection-enter，通知 notice-enter 等。
- 环境动画时长 25–85s，循环，幅度小，不抢阅读；交互过渡 0.16–0.22s。
- 统一缓动 `cubic-bezier(.2,.8,.2,1)`。
- 收藏卡 hover：`translateY(-4px)`、背景 `.024→.05`、边框 `.07→.14`、
  阴影 `0 16px 40px rgba(0,0,0,.35)` + 1px 内描边。
- 分类行 hover：只有箭头颜色 `rgb(197)→rgb(245)`，整行不动——避免大面积抖动。
- 故事板：点击第 2 张，内容卡替换，位置指示 `01→02`，折叠卡是竖排文字 + 数字 + 图标。
- 滚动：8 个 `IntersectionObserver`，4 个 rAF；无 canvas、无 WebGL、无 scroll-timeline。

我们只有 1 条入场（上浮 14px、600ms）和 hover 变色；没有环境动画、没有组件级状态过渡。

## 5. 音效（最容易被忽略的成熟度信号）

`assets/js/sound-effects.js`，382 行，全部用 Web Audio 合成，**0 个音频文件**：

| 事件 | 合成方式 | 时长 |
|---|---|---|
| hover | sine 3200→2800Hz，gain 0.08 | 50ms |
| click | sine 1800→1200 + triangle 800→600 | 60–80ms |
| success | sine C5-E5-G5 琶音 | 250ms |
| error | sawtooth 400→200 + sine 300→150 | 250ms |
| modalOpen | sine 200→600 + triangle 400→900 | 200ms |
| modalClose | sine 500→200 | 150ms |
| toggle | sine 1000→1400 | 60ms |
| notify | sine 880→1100→880 | 180ms |
| copy | square 1200→1600 双击 | 100ms |

工程细节：

- master gain 0.35，音量克制；
- 事件委托挂到全部 `button` 和 `a`，hover 80ms 节流；
- 首次 click / touchstart / keydown 才创建 `AudioContext`，尊重自动播放策略；
- 开关状态写 localStorage，按钮 `aria-pressed`，`title` 随语言切换；
- 右下 42px 白色圆形开关，hover 时图标 `scale(1.18) rotate(-4deg)`，按下 `scale(.95)`。

重点不是“加音效”，而是**把听觉也纳入交互语言**，并且给了用户一个明确的静音开关。

## 7. 排版与栅格

- H1：40.32px / 58.46 / 字距 -1.5px / 字重 580。
- H2：28px / 42 / -0.7px / 520。
- 正文：14px / 23.1；eyebrow 9px，字距 1.8px，字重 450。
- 数字用 Geist 变体，等宽场景用 Geist Mono。
- 结论：高级感来自**小字号 + 紧字距 + 大留白 + 统一基线**，不是“大标题”。

我们的 67px 宋体大标题 + 16px 正文是“杂志”，不是“产品”。这个方向没错，但缺少产品级的
密度：他们没有一处 8.5px 的中文，我们上一版还有。

## 11. 我们该补什么（按影响排序）

**P0 结构性**

1. 首页加一个真正“可操作”的模块：示例简报（切换周期 / 指标，纯 HTML + 合成数据，标注示例）。
2. 把「2×2 能力卡 + 四步时间线」合并成一块**横向折叠档案板**：采集 / 核对 / 入库 / 复盘，
   点击展开、01/04 计数、进度条，替代两块重复的介绍。
3. 桌面端常驻导航（左栏或顶部二级），含分组、当前页、回到顶部、悬浮下载；移动端沿用 dialog。

**P1 手感**

4. 音效系统：合成 6–8 种、默认低音量、可静音、尊重首次手势。
5. 状态：卡片 hover 上浮 + 阴影 + 边框；箭头位移；数字滚动；首访弹窗。
6. 页脚：大字标 + 术语跑马灯 + 版本 / 许可 / 更新入口。

**P2 内容**

7. 文案补具体数字与承诺；FAQ 从安装页挑 3 条上首页。
8. 可选：构建时静态化的 GitHub stars / 版本徽章（不引入运行时外部请求）。

建议 P0 + P1 一起做：这是把“宣传单”变成“产品官网”的最小组合。
