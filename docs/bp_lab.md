# BP 概览五视图 · 九区 + 策略沙盘 + 英雄诊断（2026-11-15 重建）

`#bp` 不再挂旧 BPI 十视图、战队 BP、抗针对三个子页。现在按五个分析视图组织，
共享数据源、时间窗口与本队/对手筛选；教练档案仍在 `#coach`。

原来的「历史对抗查询」和「对手重点防」合并为第 03 区：**针对指定对手的历史阵容研究**。
通用查询（任意英雄 / 组合 / 完整阵容）保留在第 03 区底部的「高级查询」里。

## 数据源与口径

| 来源 | 范围 | 手序 | 版本 |
|---|---|---|---|
| KPL | 4,702 局，含挑战者杯；可按全部 / KPL 联赛 / 挑战者杯筛选 | 每方 `picks`/`bans` 数组**按该方手序**；不还原全局交错手序 | 0 条已记录 |
| 训练赛 | 本机营地面板 104 局，8 个日期 | 按规则自动还原（排位/巅峰 rank-20，每方 5 Ban + 5 Pick）；92/104 可生成事件，其余 Ban 不足待补 | 0 条已记录 |

硬规则：

- KPL 与训练赛胜率**不混池**；页面分别计算、分别标注。
- 「第 N 手 / 第一手 / Ban 后选择」= 该队数组顺序；页面会写明不是全局交错手序。
- 版本为空时显示「版本未记录」，用时间窗口观察，不从日期推断版本。
- 五人整阵容 KPL 最高 9 局；样本不足时只显示「见过 / 待验证」，不输出稳定胜率结论。

### 自选组合与区内时间窗

- **02 组合强度**：英雄头像选择器；点选 2–3 个英雄自动查同队同局记录。组合结果包含
  命中局数、使用率、胜率 / Wilson、单英雄收缩基准、相对基准、近 7/15/30 天、阵营、
  常见搭档、对手分布与证据局。点下方榜单里的组合可直接带入。
- **04 / 08**：保留原有下拉，同时提供「用头像自选目标 / 组合」，支持 1–3 个英雄。
- **区内时间窗**：01–09 与诊断主区的标题下都有近 7/15/30 天按钮。切换后全页时间口径
  同步，但视口停留在当前分析区；自定义日期仍在顶部工具栏，区内会显示范围并可一键改回。
  选择“全页同步”是有意的：同一页各块用不同时间窗会让结论不可比。

### 03 区的四个块

1. **对手组合使用**：对手同队同局的双/三人组合，局数、使用率、胜率、样本。
2. **对手组合的反制**：选定对手组合后，哪些敌方组合曾有效应对它；显示对手胜率与反制胜率。
3. **对手英雄使用**：对手英雄的 Pick 次数、Pick 率、胜率、样本。
4. **英雄反制**：选定对手英雄后，同局敌方英雄对它的历史反制胜率。

### 03 区行为画像

- 阵营 1 / 2 的第一手 Pick、第一手 Ban。
- 看到我方第一手后，对手的第一手分布（同局共现，不还原交错手序）。
- 上一局失利 / 取胜后的下一局胜率、第一手变化率、Ban 变化率。
- 对手选手的英雄池、常用英雄与第一手次数。

「组合/英雄反制」只统计同一局的历史共现，不是因果克制；样本不足 3 局不展示。
「特定 BP 局面」= 阵营（1/2）、对手第一手、指定对手组合、指定对手英雄。

### 诊断视图：N01–N16

第五个视图不新增区号，而是在「己方英雄诊断」下按 6 个诊断段展开：

| 段 | 对应 | 输出 |
|---|---|---|
| 表现 | N01–N02 | 英雄使用胜率 / Wilson / 前窗变化；敌方英雄同场时的我方胜率、敌方双人组合、可选指定敌方阵容专项 |
| 趋势 | N03–N04 | 近 7/15/30 天（各带前一个等长窗口）、自然周序列；敌方英雄按周的反制波动与极差 |
| 异常 | N05–N06 | 当前 vs 基准胜率降幅、z 检验、p 值、显著性与严重度；当前≥5 局才判定，基准不足 3 局自动退回历史并标注 |
| 定位 | N07–N11 | 搭档、敌方英雄、同分路对位、使用选手、对手/阵营/赛事分布 |
| 归因 | N12–N14 | 阵容因素与胜率变化并列（不写因果）；逐人 KDA/经济/输出/承伤/参团/推塔；有回放时 2/4/10 分钟经济差 |
| 阵容 | N15–N16 | 当前/前窗逐局阵容、按月多周期；搭档/敌方/对位英雄集合差异，前窗不足 5 局不判定新增/消失 |

数据门槛：

- KPL 没有逐人经济、KDA、输出与回放事件：N13 显示“无逐人统计”，N14 显示“无经济曲线”，
  不用队伍经济或个人推算冒充。
- 训练赛逐人统计来自营地 `battleStats`；只有营地明确给出选手-英雄映射时才计入。
- N12 在前窗同英雄不足 5 局或没有共同因素时不做关联；N16 在前窗不足 5 局时不做新增/消失；N05/N06 当前不足 5 局只作观察。
- 所有“反制/关联/差异”都是历史共现，不写成因果。

## 策略沙盘（P2）

- 规则只走征召 18 手 / KPL 20 手；KPL 证据只作历史参考，不套用 KPL 规则。
- 输入：规则、赛制、我方阵营、当前 BP 前缀；输出：合法下一手、按历史证据加权的候选、
  对手一步回应（历史频率，不是预测）。
- 当前只做「当前局 + 一步回应」；跨局 history 接口已留，UI 尚未做逐局录入；
  多步搜索与 BO 系列回测属于 P3，未在本次交付中声称完成。

## 已知边界

- 逐手顺序：营地名单按格式自动生成 18/20 手事件（当前 92/104 局，其余 Ban 不足待补）；KPL 仍只有每方数组顺序。真正的 KPL 全局交错、两步回应、决策树仍待补采。
- 版本：KPL/训练赛均无版本标签；版本对照、版本归因暂不可做。
- 对手画像：训练赛对手多为占位名，样本常为 1–5 局；只作单场观察。
- 五人阵容：KPL 最高 9 局，不输出稳定胜率。
- 时间对比：环比是前一个等长窗口，同比是去年同日期；训练赛只有 8 天，同比通常为空，不做硬对比。
- 策略沙盘：当前只做「当前局 + 一步回应」；跨局 history 接口已留，但 UI 还没做逐局录入；多步搜索与 BO 系列回测属于后续 P3。
- 英雄诊断：KPL 无逐人经济/KDA/输出与回放事件，N13/N14 明确不可用；训练赛也只在营地统计/回放匹配存在时计算。N12/N16 前窗不足 5 局不做差异。
