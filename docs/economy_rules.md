# 王者荣耀经济规则（截图提取）

- 提取日期：2026-11-01
- 来源：`内部资料/` 下 15 张图文截图（小红书号 94189028047，训练营/指挥官模式实测）。其中一页上半部分为少司缘技能描述，与经济无关，未纳入。
- 用途：复盘口径参考（装备被动、经济分摊、兵线时序与兵线经济表）。本文件不改变工作台任何统计口径，不写入数据库，不进入正式统计。
- 单位：金币 g；时间单位 s。「单人补刀经济」指一名玩家独吃整波兵（或一只野怪）并全部补刀后的到手金币，等于 150% 基础经济。
- 波动：实测每名小兵有约 ±1~2g 的波动（第一波波动可能更大），计算值与实测值不必逐金相等。
- 现行口径修正：**三级打野刀没有「不分经济 / 不分兵线经济」被动**（用户 2026-11-01 确认）。原文把「二级/三级野刀」并列的表述，按此口径只对二级打野刀成立，见 §1.2、§1.3。

## 1. 经济相关装备

### 1.1 辅助装

| 等级 | 被动金币 | 不分经济 | 拾取金币上限 |
|---|---|---|---:|
| 一级辅助装 | 5g/3s | 是 | — |
| 二级辅助装 | 5g/3s | 是 | 450g |
| 三级辅助装 | 6g/3s | 是 | 600g |

- 「不分经济」对兵线和野怪都成立：辅助不占分摊名额，也不拿基础经济。
- 这不等于辅助没有收入：辅助装自带每 3 秒跳钱，并有拾取金币（累计上限 450 / 600）。
- 原文未说明辅助自己补刀时是否仍拿 +50% 补刀经济。按「分摊只针对基础经济」推断，补刀加成应照常结算，但需实测确认。

### 1.2 打野刀

| 等级 | 不分兵线经济 | 野怪经济 | 说明 |
|---|---|---|---|
| 一级野刀 | 是 | — | 原文仅列「不分兵线经济」 |
| 二级野刀 | 是（仅 4min 前；辅助装在旁时失效） | 120%（额外 +20%） | 700~1000 码只有低保 |
| 三级野刀 | **否**（用户修正） | 120% | 原文「二级/三级」并列的句子按此口径只对二级成立 |

- 「120% 野怪经济」与正文「打野刀额外 20% 经济」是同一件事：打野从野怪身上多拿 20%。
- 二级野刀另有叠被动层数的加成：700 码以内生效，700~1000 码不生效。
- 三级野刀的叠层 / 额外比例原文没有单独给出，只有 120% 这一条，不要外推。

### 1.3 装备交互与「打野经济最大化（三人并线原则）」

- **辅助装在场时，二级野刀「不分兵线经济」被动失效**，打野重新计入兵线分摊。
- 辅助装本身永远不占分摊名额（兵线、野怪都不占）。
- 因此「辅助 + 打野 + 对抗路/中路/发育路」同时吃一波线时，实际只有打野和线上两人参与分摊：
  - 补刀者（线上）：80% + 50% = 130% 基础经济
  - 打野：80% 基础经济
  - 团队合计：210% 基础经济
- 与打野被动正常生效时（线上单人补刀 150%、打野 0）相比：团队 +60 个百分点，打野 +80 个百分点，线上补刀者 −20 个百分点。原文认为这样更有利于打野带动整体节奏。
- 三级野刀没有该被动，因此不存在「被动失效」这一步：三级刀打野在分摊距离内本来就参与分配；辅助在场时同样按两人分摊（结果仍是 210%），但不需要靠辅助触发。
- 原文把这条原则限定在「4min 前」，与二级野刀被动的时间窗口一致。

## 2. 基础经济来源

### 2.1 开局经济

开局 300g（原文记作 300g）。

### 2.2 自然增长经济

从开局第 30s 开始，每秒自动获得 3g，包含第 30s。

```text
自然增长累计(t) = 3 × max(0, t − 29)     # t 为对局秒数
```

例 5-1：到 3min30s（t = 210s）时，纯自然增长经济为

```text
3 × (210 − 29) = 543g
```

原文算式 `(31 + 2×60 + 30) × 3 = 543g` 等价：从第 30s 到第 210s 共 181 个整秒。

常用时间点：

| 时间 | 自然增长累计 |
|---|---:|
| 1min | 93g |
| 2min | 273g |
| 3min | 453g |
| 3min30s | 543g |
| 4min | 633g |
| 10min | 1713g |

## 3. 兵线 / 野怪经济分配

### 3.1 基础经济与补刀经济

- 单位经济 = **基础经济 + 补刀经济**。
- **基础经济**：只要在单位死亡时处于分摊距离内即可获得，按人数分摊。
- **补刀经济**：只有补到最后一刀的人获得，固定为 **50% 基础经济**。
- 分摊只作用于基础经济，不作用于补刀经济。
- 单人独吃并补刀：100% + 50% = **150% 基础经济**，即「单人补刀经济」。

### 3.2 多人分摊表

n 为实际参与分摊的人数（装备被动会让某些单位不计入，见 §3.3）：

| 分摊人数 n | 每人基础份额 | 补刀者实得 | 未补刀者实得 | 团队合计 |
|---|---:|---:|---:|---:|
| 1 | 100% | 150% | — | 150% |
| 2 | 80% | 130% | 80% | 210% |
| 3 | 55% | 105% | 55% | 215% |
| 4 | 43% | 93% | 43% | 222% |
| 5 | 37% | 87% | 37% | 235% |

```text
个人实得 = 份额(n) + (补刀 ? 50% : 0)
团队合计 = n × 份额(n) + 50%
```

- 团队总经济随人数单调上升（150% → 210% → 215% → 222% → 235%），但单体份额下降。
- 原文结论：**2 人吃线/吃野最优**——团队总经济 210%，补刀者单体 130%，兼顾总量与个体。
- 5 人同吃只适合极端抢线/推进场景，单兵收益很低。

### 3.3 不计入分摊的单位

| 单位 | 兵线分摊 | 野怪分摊 | 条件 |
|---|---|---|---|
| 辅助装 | 不计入 | 不计入 | 始终 |
| 二级野刀打野 | 不计入 | 正常 | 4min 前、处于兵线分摊距离内、辅助装不在旁 |
| 二级野刀打野 + 辅助装 | **计入** | 正常 | 4min 前，辅助装在旁使被动失效 |
| 三级野刀打野 | 计入 | 正常 | 无「不分经济」被动（用户修正） |

- 「不计入」意味着不占名额：2 人吃线时若有 1 人出辅助装，实际按 1 人结算（补刀者 150%，辅助 0 基础份额）。
- 「计入」意味着占名额并拿 80%（2 人分摊时）。

### 3.4 极限距离

| 场景 | 距离 | 效果 |
|---|---|---|
| 无二级野刀，吃兵 / 吃野基础经济 | 1000 码（2.5 个闪现） | 可获得基础经济；这对应兵线视野的极限距离 |
| 二级野刀，对野怪 | 700~1000 码 | 低保：只有基础经济，+20% 与叠层不生效 |
| 二级野刀，对野怪 | 700 码以内 | 全额：+20% 与叠层生效 |
| 二级野刀，对兵线 | 700~1000 码 | 不分兵线经济（4min 前被动生效） |

- 精准普攻判定：精确普攻圆圈与目标圆圈**相切或相交**即可吃到；相离吃不到（相离一点点仍可能吃到，再远一点就不行）。
- 原文只给出「700~1000 码」这一区间，**700 码以内的兵线分摊行为没有写**，不要在计算中自行假设。

### 3.5 计算示例（例 6-1）

条件：中路、发育路、辅助三人同吃一波线；补刀全由发育路完成；辅助出二级辅助装。
这波线的单人补刀经济为 `90 + 70 + 70 = 230g`。

```text
基础经济 = 230 / 150% = 60 + 46 + 46 ≈ 152g（逐兵四舍五入）
补刀者（发育路） = 152 × 130% = 78 + 60 + 60 = 198g
未补刀者（中路） = 152 × 80%  = 48 + 37 + 37 = 122g
辅助              = 0（辅助装不参与兵线分摊）
团队合计          = 198 + 122 = 320g ≈ 230 / 150% × 210%
```

- 单人补刀 230g 的同一波线，三人吃后团队合计约 320g：团队 +90g，发育路 −32g，中路 +122g。
- 若换作「辅助 + 打野 + 线上」，且二级野刀被动因辅助失效，数字相同（130% / 80% / 210%）。
- 金币换算存在约 1g 的波动：`70 / 1.5 = 46.6`，实测可能是 46 也可能是 47，不是严格四舍五入。计算值有效，不要追求逐金吻合。

## 4. 兵线时间轴

### 4.1 刷新与交汇

```text
第 n 波刷新时间 T(n) = 10 + 33 × (n − 1) = 33n − 23    # 单位 s
第 n 波交汇时间 I(n) = 30 + 33 × (n − 1) = 33n − 3     # 仅 10min 内按此式
```

- 第一波 10s 刷新、30s 交汇，之后每 33s 一波。
- 4min 内 7 波；10min 内 18 波；20min 内 37 波。
- 第 8 波在 4m01s 刷新（跨过 4min）；第 19 波在 10m04s 刷新（跨过 10min）；第 37 波在 19m58s。
- 10min 后兵线移速增加，交汇时间更短；原文没有给出新的交汇公式或数值。

### 4.2 前期分路差异（4min 以内 / 前 7 波）

| 分路 | 组成 | 特点 |
|---|---|---|
| 对抗路 | 1 近战 + 2 远程（3 个） | 3 个均为经验兵（额外经验，不加金币） |
| 中路 | 2 近战 + 2 远程（4 个） | 小兵数量多 1 个 |
| 发育路 | 1 近战 + 2 远程（3 个） | 3 个均为经济兵（额外金币） |

- 4min 前出现超级兵会改变上述差异化原则（见 §4.5）。

### 4.3 中后期与后期（非超级兵）

- **4~10min（第 8~18 波）**：三条分路差异消失，三路完全相同，均为「近战小兵 + 远程小兵 + 弩车」。
- **10min 后（第 19 波起）**：兵线经济成长停止，组成仍为「近战小兵 + 远程小兵 + 炮车」，每波单人补刀经济恒为 290g；大后期（20min 后）与第 19 波完全相同。
- 原文换算：第 19 波 290g ≈ 第一波中线单人补刀 208g × 140% = 291.2g，误差 2g，原文推测由 3 个兵造成。
- 成长在 10min 前仍在继续（第 13~18 波 260→286），「10~20min 经济完全相同」应理解为第 19 波之后恒定，而不是 10min 前的波次也恒定。
- 以上均为非超级兵波次；超级兵波次另有一套数值（第 19 波起 308g/波），见 §4.5、§5.6。

### 4.4 龙兵经济

| 触发 | 效果 |
|---|---|
| 击败主宰 | 替换 2 波兵线 |
| 击败暗影主宰（小龙） | 替换 2 波兵线 |
| 释放暗影之径 | 生成龙兵 |
| 击败风暴龙王 | 替换 3 波兵线 |

- 所有种类龙兵的单人补刀经济均为 **180g**。
- 原文没有说明替换的是哪几路、是否双方同时替换、替换后波次编号如何变化。

### 4.5 超级兵

- 训练营和指挥官模式实测：超级兵最快从第 3 波开始出现。
- 4min 以前的超级兵会改变原先 4min 前的兵线差异化原则。
- 超级兵波次的组成为「超级兵 + 近战小兵 + 远程小兵」。
- 只要是同一波，三路超级兵兵线的经济完全相同。
- 实测数据从第 3 波开始（第 1~2 波无数据），每名小兵误差 ≤2g；第 19 波起恒定，单人补刀 308g/波，完整表见 §5.6。
- 从第 8 波起，超级兵波次的近战/远程数值与普通中后期波次基本一致（差异 ≤2g），超级兵取代炮车位：第 8 波 123+70+60（普通 70+60+108），第 19 波 150+85+73（普通 85+73+132）。
- 第 3~7 波的近战/远程数值与普通分路表不同（如第 3 波 112+63+54；普通对抗路 78+58+58、中路 46+46+60+60、发育路 84+64+64），按实测使用，不要套用普通分路表。

## 6. 可直接计算的基线

以下数值只用于复盘对标，假设：单人吃线、每波全部补刀、处于分摊距离内、不含野怪/击杀/助攻/推塔/龙/辅助装/装备加成。

```text
自然增长累计(t) = 3 × max(0, t − 29)
兵线累计(t)     = Σ 单人补刀(n)，对所有 I(n) ≤ t 的波次求和
```

| 时间 | 自然增长 | 对抗路兵线 | 中路兵线 | 发育路兵线 |

| 2min | 273g | 574g（3 波） | 628g（3 波） | 632g（3 波） |
| 4min | 633g | 1398g（7 波） | 1550g（7 波） | 1542g（7 波） |
