## 意义

之前说经济/KDA 很难，是因为只盯 `.abc` 字节。回放 UI 本身提供了：

- 任意时刻的逐人 **KDA**（当前累计）；
- 任意时刻的逐人 **当前金币**（底部面板）；
- 顶部团队 **累计金币/击杀**；
- 装备、等级、技能等面板。

这不需要模拟，也不需要账号内数据接口，只需要在回放 UI 里按时间暂停/切换选手。
下一步可以按 `03:05 / 06:00 / 09:00 / 终局` 采样，形成逐人 KDA/当前金币时间序列；
再和营地 30 秒团队累计金币对拍，用差值估算逐人支出。

## 边界

- 底部金币的准确口径（当前可用 vs 累计获得）仍需多点对拍；
