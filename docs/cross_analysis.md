# 跨局分析 / 大场分析（两个独立模块）

> 2026-11-15 重构。**跨局分析**（`#cross`）与**大场分析**（`#biggame`）是两个并列模块：
> 前者把多场 BO3/5/7 放在一起看；后者是单场 BO 的独立分析界面。
> 页面：`v3/public/cross-page.js`、`v3/public/biggame-page.js`；样式：`cross.css`。

## 1. 两个模块

| 路由 | 模块 | 回答的问题 | 数据 |
|---|---|---|---|
| `#cross` | 跨局分析（多场 BO） | 几场 BO 放在一起：大场战绩、局序、赛中归因、赛后归因、英雄与 BP | `/api/cross/series-summary` + `/api/cross/vectors` |
| `#biggame` | 大场分析（列表） | 有哪些已确认大场，各自比分/完赛/关注 | `/api/cross/series-summary` |
| `#biggame/<id>` | 大场分析（单场） | 这一场 BO：逐局走势、局间调整、对手回应、BP 账本、败局恢复 | `/api/series/<id>/analysis` |

入口：顶部「对局档案」次级导航同时有「跨局分析」「大场分析」；`#cross` 页头也提供
「大场分析 →」交叉入口。`#cross/series/<id>` 旧链接自动重定向到 `#biggame/<id>`。

## 2. 跨局分析（`#cross`）四段

概览条只描述样本与结果；下面四段各司其职，用分区切换（URL `view=overview|ingame|postgame|draft`）。
默认全部用可视化：条形、区间、点线、人卡、哑铃、热力格；表格只在图表的 B 视图 / 精确对账里出现。

### 01 概述【跨局描述性分析】

只描述这批大场的构成与结果，不做因果/建议：

- **样本构成**：大场数、小局数、对手数、日期跨度、BO3/5/7 构成、完赛/待核实/比分异常
- **胜负与结构**：大场胜率、小局胜负、场均局数、打满/零封、比分分布、G1..G7 局序胜率
- **小局分布**：时长、10 分钟经济差、终局经济差的 P10/P50/P90
- **对手**：按对手分组的大场/小局战绩、打满场次
- **覆盖**：经济/回放事件/阵容/选手面板有效局数

描述性百分比都给分母；解释性结论在赛中、赛后、英雄和 BP。

### 02 赛中【用赛中数据做归因】

数据：各局经济时间线、回放事件、逐秒位置。

- 经济路径：0/5/10/15/20/25 分钟累计差、三段净增、10 分钟后变化
- 前期节奏：一血/一龙/一塔、4 分钟领先率、打野过河/深入/反野
- 五路对位：分均经济差、P10 下限、领先率、领先/落后时胜率
- 资源兑现：控龙率、推塔差、10 分钟领先 → 龙/塔 → 胜的漏斗
- 领先守成：大优被翻、大劣翻盘、超长局
- 团战结构：多打少/少打多、首杀归属、有击杀团战分母

### 03 赛后【用赛后数据做归因】

数据：十人结算面板、终局经济、时长、结果；不混入赛中事件。

- 赢输驱动：终局经济、人头差、时长、死亡、五路分均差（秩差 + 前后半复现）
- 选手执行：分均经济、分均输出、参团率、场均死亡（出场≥3 局）
- 五路结果：分均差、领先率、领先/落后胜率
- 结果分布：终局经济差与时长 P10/P50/P90、崩盘/大胜/超长局
- 本轮关注：连败收尾、败局后未改善、编组待核实（按系列赛结果，属赛后）

### 04 英雄和 BP【重点】

数据：双方五人阵容、ban 位、功能标签、系列赛全局 BP 账本。

- 阵容结构：五路英雄签名、打法类型、功能标签（双前排/强开团/保护链/清线转线/无前排）
- 我方英雄池：出场、原始/收缩胜率、10 分钟差
- 对手英雄：对手常用英雄及「他们拿这个英雄时我们胜率」
- 双人组合：组合胜率 vs 不含该组合的基线（lift）
- 蓝红方与 ban：蓝/红方胜率、我方 ban、对手 ban 我们
- 全局 BP 消耗：每个局序平均累计曾选、本局新增、规则集
- 选手-英雄舒适度：同一选手+英雄至少 3 局的胜率

没有手序时只按终局阵容谈「换人」，不推断「第几手针对」；1 局 1 胜不显示成 100%。

## 3. 大场分析（`#biggame`）

### 列表

- 独立模块入口；卡片按开赛日倒序，显示日期、BO、对手、比分、完赛、G1..Gn 胜负、
  比分异常/待核实/关注数。
- 筛选：时间 / 赛制 / 对手 / 训练组 / 状态 / 完赛状态。

### 单场

- 页头：BO、对手、比分、完赛、规则集、日期；一句大场结论
- 系列赛结论：逐局迷你卡 + 10 分钟/终局走势
- 逐局对比：结果、时长、10′差、终局差、双方体系、调整幅度、单局复盘
- 调整与对手回应：相邻局我方/对方新增移出、体系变化、重复 ban
- 全局 BP 账本：每局累计曾选、我方已锁、本局新增、规则集
- 败局恢复：输局后的下一局结果与 10 分钟差；体系延续/切换后的下一局胜率
- 覆盖与口径：向量/明细/手序/过程覆盖与 caveats

## 4. 数据与校验

- 跨局：一次取系列赛汇总 + 各局向量；按选中大场的 `seriesId` 过滤小局。
- 大场：列表取系列赛汇总；单场取 `/api/series/<id>/analysis`。
- 标准决胜：BO3 任一方最多 2 胜，BO5 最多 3 胜，BO7 最多 4 胜；`completionMode=fixed`
  允许打满，比分是小局比分。
- BO3 出现 0:3 等与赛制不一致的比分：列表/详情标「比分异常」，先核实编组/规则集，
  不据此谈直落/逆转。
- 同一 BO 内小局不作为独立实验；大场胜率只算分出胜负的系列赛。
