## 0. 边界（硬要求）

- **不造假**：没有对局就不生成战况；样本不足不写「显著 / 稳定」，只写「本批观察」。`null` 就是 `null`，不补 0。
- **术语**：教练可见文案只用赛训/比赛语言（对线期 0–4 分钟、发育期 4–10 分钟、后期 10 分钟以后、龙团、掉点、推塔、领先兑现、被翻盘、阵容体系）。
  「Wilson / 分位 / 聚类 / 效应量 / 模型」只允许出现在 `deep` 明细或「查看计算依据」里，默认简报不出现。
- **口径统一**：同一请求内，摘要句、指标卡、发现卡、证据对局必须来自同一套 `from/to/opponent/source/validation`；上一周期一律取「等长紧邻区间」。
- **下钻带筛选**：`primary_destination` / `deep_destination` 必须携带当前筛选（`from/to/opponent/source/validation`），不得统一跳到同一个固定页面。
- **下钻落地页用稳定模块页**（分析专题页正被并行任务增删，不写死）：`#match/<真实对局 key>`（证据对局）、
  `#matches`（比赛/团战/龙塔类结论）、`#players`（分路/阵容类）、`#bp`（阵容体系）、`#sources`（数据覆盖）。
  前端在点击证据对局时先把链接里的 `from/to` 写回全局筛选，再跳转，保证目标页与简报同一期；`deep_destination` 仍按同一期生成，首页不再显示「更多分析」入口
  （目标页只认全局筛选，不读 hash 里的查询串）。
- **证据对局 key**：接口里的 `evidence[].game` 必须是能打开 `#match/<key>` 的真实 key（`channel-…`），
  后端把营地 seq 映射成 match key；映射不到就不给链接，禁止 `#match/null`。
- **只读**：接口只读，不写任何数据。

## 1. 周期定义

| period | 本期 | 上期（等长紧邻） |
|---|---|---|
| `today` | 今天 | 昨天 |
| `week` | 本周一 ~ 本周日 | 上周一 ~ 上周日 |
| `month` | 本月 1 日 ~ 月末 | 上月 1 日起、与本月**等天数**（跨月按自然日回退，月末截断） |
| `custom` | `from` ~ `to`（含两端） | 紧邻其前的等长区间 |

- 日期均为自然日（服务器本地时区）。
- 本期 0 局时**不回退**别的周期：`available=false`，由前端显示空态 +「最近一批对局在 X～Y」的快捷入口（接口给 `fallback_hint`）。
- 上期 0 局：允许，`prev.games=0`，比较文案写「上期暂无可比数据」。

## 2. 接口

`GET /api/briefing`

参数：`period=today|week|month|custom`（默认 `week`）、`from`、`to`（`custom` 必填，`YYYY-MM-DD`）、`opponent`、`source`(默认 `db,bundle`)、`validation`(1/0)。

### 2.1 候选信号（后端实现清单）

> 这 8 项是**底层过程分析**口径，首页指标卡已不再使用（见实现状态）；
> 它们仍用于 `classic_metrics=True` 的口径回归与 `deep_destination` 字段；首页不再显示「更多分析」入口。

每条都算「本期值 / 上期值 / 样本 / 方向」，只保留有证据对局的：

| id | 口径 | 证据 |
|---|---|---|
| `lead_hold` | 10 分钟经济差 ≥ +1000 的局，最终胜率（分子/分母） | 领先但输掉的局 |
| `comeback` | 最大领先 ≥ +1000 且告负（被翻盘）的局数 / 领先局数；平均回撤 | 被翻局 + 回撤时刻 |
| `fight_arrival` | 开局 3 秒人数落后（≤ -1）与不落后（≥0）的团战胜率差；迟到率 | 落后团战输掉的对局 |
| `fight_trade` | 团战击杀差（我方 - 对方），团灭次数 | 击杀差 ≤ -2 的团战所在局 |
| `objective` | 每局拿到资源/建筑数（龙、塔等），龙团后 120 秒内转为推塔/控龙的次数 | 资源被对手拿得多的局 |
| `comp` | 阵容体系集中度 / 常用英雄或组合变化（如射核占比、双人组出场） | 使用该体系的局 |
| `roster` | 分路经济/输出占比、死亡数的本批波动；换人前后 | 异常分路所在局 |
| `coverage` | 有面板无回放的局数；缺时间轴的局数 | 缺回放的局 |

排序规则（全后端定，前端不再排序）：

1. 只保留 `n(本期) >= 2` 且能找到至少 1 局证据的候选；同 kind 只保留 1 条（取价值最高），`comp/roster` 与 `objective` 各最多 1 条 → 最多 3 条。
2. 价值分 = `|方向化变化| × 样本权重 × 证据权重`，其中变化必须**跨周期可比**：
   - 比例类：`p_cur - p_prev` 的百分点差（分母 ≥ 3 才算数）；
   - 计数/均值类：相对变化 `(v_cur - v_prev) / max(|v_prev|, 1)`，样本 < 3 时乘 0.5；
   - 上期样本 < 3：降低权重并 `enough=false`，文案写「上周样本不足，只作观察」。
3. 同方向、同主题（领先类/团战类/资源类/阵容类）只留 1 条；战绩本身不再单独做发现卡（已在摘要与指标里）。
4. 若所有候选都无变化：`findings=[]`，`metrics` 取最接近整期水平的 2–3 个，`summary.note` 写「本期与上期相比没有明显变化」。

### 2.2 文案模板（教练语言，禁用统计词）

- 摘要句：`本周 6 局训练赛，4 胜 2 负，集中在 11-02 ~ 11-04。`（上期有对局才补「比上周同期多赢 N 局」；上期无对局直接收句，不写「暂不可比」；不复述胜率）
- 战况小字：`战绩来自营地终局面板，比赛过程以官方回放为准。`（只有面板的局补一句去「采集」补齐；不写「仅作本批观察」）
- 发现句：`主题 + 变化` + `本期数字` + `上周数字`，例：
  - 领先类：`十分钟领先后，丢掉优势的局变多了。本周 6 局十分钟领先赢下 4 局，上周同期 5 局全胜。`
  - 团战类：`开局人少还硬接团的情况变多了。本周 9 场人数落后团战只赢 2 场，上周 7 场赢 4 场。`
  - 资源类：`龙塔争夺的收益变差了。本周每局拿到 2.1 个资源/塔，上周 2.8 个。`
  - 阵容类：`阵容更集中在中野。本周 5 局用同一套双人组，上周 6 局用了 4 套不同组合。`
- 每张发现卡最多 1 句结论 + 2 个数字 + 最多 2 条对局证据 + 1 行限制说明。

### 2.3 空态 / 异常

| 情况 | 首页表现 |
|---|---|
| 本期 0 局 | `available=false`，前端：`本周还没有对局` + 训练安排 +「查看最近一批（X～Y）」（`fallback_hint`）+ 去采集 |
| 空库 | 沿用现有「还没有对局数据」弹窗（三种入库入口），不再整页换向导 |
| 上期 0 局 | 指标卡不做周期对比，照常展示本期值；摘要句直接收句，不留「暂不可比」 |
| 缺回放 | `coverage.note` 写「X 局只有面板、没有过程」，发现卡不使用缺时间轴的口径 |
| 对手未命名 | 证据标签用「对阵 #29」这类当前系统命名，不编造队名 |
| 取数失败 | 模块内错误 + 重试；其他区块不保留旧结论 |

## 4. 验收

后端单测 `tests/test_period_brief.py`（合成夹具）：
- 周期同进度窗口（周/月按今天截断）、`custom` 等长与跨月回退、非法日期 400；
- 8 项指标：6 固定 + 2 动态、比例写成 xx/xx（百分率）、经济用金币、每项带有效数据量与同批排名；
- 上期为空写「上期暂无可比数据」，不算假变化；
- 复盘区 10 个字段：目录顺序、每局 `values`、丢龙/被推塔/终局经济/输出占比口径、异常条件
  （十分钟领先 / 零丢龙 / 正经济差 / 输出占比 ≥50% 不进组）、没有面板或事件不补 0；
- 场景：今日无比赛、本周有上周无、仅有终局面板、过程缺失、重复记录、对手未知、自定义跨月；
