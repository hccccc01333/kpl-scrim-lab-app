# 使用指南

统一入口：[打开赛训分析](http://127.0.0.1:8766/studio)。

## 启动与停止

首次运行 `安装依赖.bat`。日常启动用 `启动工作台-后台.vbs`，随后在浏览器打开统一入口；停止用 `停止工作台.bat`。排查启动错误时运行 `启动工作台.bat` 查看输出，保留窗口。启动脚本文件名保持兼容。

## 导入一场比赛

1. 点击右上角“导入比赛”，进入“采集一局”。填写日期、对手和训练分组，点击“创建并导入”。这些信息可在本局继续修改。
2. 本局必须提取并关联王者营地网页链接，关联七种赛后截图及一段完整录屏对应的一份 JSON 报告。表格与回放文件选填，补充或校正字段。具体获取链接、录屏起止、必开面板和七张截图示例见 [采集 SOP](collection_sop.md)。单独上传截图、录屏或回放，不会自动证明它们属于同一局，需要核对后关联。
3. 查看字段冲突，补齐英雄、昵称、比分、阵营及可用数值，保存草稿修订。填写复核人并完成审核，再保存本局数据。
4. 点击“开始本局复盘”，直接进入对应比赛。保存后的数据变化会刷新分析数据；未保存的采集候选不进入正式统计。

创建失败时，页面保留输入并提示错误，可直接重试。“管理已有比赛”进入采集通道列表，比赛档案则展示可供分析的比赛记录。

## 从比赛进入复盘

首页的“复盘最近一局”和最近比赛列表都直接进入单局。需要找其他比赛时，进入“比赛档案”，搜索标题、对手或日期；更多条件在“筛选数据”中，列表支持加载更多。

单局按“赛果与阵容 → 经济过程 → BP 补录 → 十人数据”阅读，点击章节按钮直接定位；“十人数据”会自动展开。阵容中的英雄和选手名字可以直接进入详情。顶部面包屑返回上级，浏览器返回键可沿原路径返回。

经济摘要来自已有采样点：最大领先只表示观测范围内的最大值，末次经济差标明观测时间，不保证等于终局经济差。没有时间轴时不补画过程。击杀候选的时间、累计值或增量与终局比分冲突时，整组收进“原始候选（待校对）”，不作为可靠击杀记录。蓝红比分与本队胜负分开标记，本队阵营未知时会提示。

## 查看选手、英雄和对比

顶部“选手”或“英雄”进入卡片列表。详情保留样本数、有效指标、最近比赛与原始比赛入口。选手昵称未绑定前，不当作已确认的稳定身份。

顶部“对比”提供“选手对比”和“英雄对比”；列表“建立对比”进入对应类型的对比页；从详情底部“对比选手/英雄表现”进入时，会保留当前对象作为 A，再选择 B。胜率以有明确胜负的样本为分母，不把未知赛果当成失利。

## 查找入口与项目维护

顶部按“首页、比赛、战队、选手、英雄、BP、对比、数据”直接进入功能，保留原路径，点击名称进入该组首页；桌面点击名称旁的展开按钮查看子页，手机使用横向二级导航。全局搜索覆盖比赛、选手、英雄和功能。导航菜单、项目工具都支持 Escape 关闭。

刷新、备份、恢复和独立 2D 回放入口在右上角“项目工具”。备份范围与目录限制见 [统一平台说明](unified_platform.md)；原始录屏等独立目录仍需单独备份。数据路径可从 [本机健康检查](http://127.0.0.1:8766/api/health) 查看。

## 遇到问题

- 页面仍显示旧布局：按 Ctrl+F5 强制刷新。
- 连接失败：确认服务正在运行，打开本机健康检查；用前台启动脚本查看错误。
- 分析为空：先检查来源、日期筛选、采集是否已审核保存、选手身份是否绑定。
- OCR 识别不完整：保留原图，人工校对；不要用猜测补全字段。详见 [OCR 引擎说明](ocr_engine.md)。

## 数据处理和报告在哪里

在“数据”中进行采集、清洗、数据集维护和字段核对。统计实验和模型实验归“数据”，报告归“战队”。近期状态、双人搭档和资源产出归“选手”；英雄池、同英雄参照和阵容关联归“英雄”；前期转化、经济转折和训练组汇总归“战队”。旧 `#analysis` 地址保留为全部功能目录；原有 `#lab`、`#models`、`#reports` 等链接继续可用。

## 新版分析怎么读

### 表现探索：散点和矩阵

进入“选手”或“英雄”，先看“表现探索”。横纵轴可切换分均经济、分均输出、KDA、参团和占比；圆的大小表示对象样本量，颜色表示已知胜率是否达到 50%，灰色为未知。虚线只是当前视图的中位数，跨分路不直接作能力评级。

点选圆点，或用 Tab / Enter 选中，右侧查看原值、样本及详情入口；“以此对象建立对比”会保留对象。按最低样本和名字筛选只影响本探索视图，页面其他资料卡沿用全局筛选。密集数据最多绘制样本最多的 120 个对象。

切换“指标矩阵”，单元格数字是原值，颜色是该列当前筛选对象内的分位，不把经济、伤害和 KDA 混成综合分。缺失显示斜纹和“—”，真实零保留为零。点列名排序，每页 40 行，点名字查看对象。导出的是当前探索筛选下的对象数据 CSV。

胜率区间采用独立胜负样本的 Wilson 近似，显示已知赛果分母；训练局可能相关、小样本区间很宽，不把它当作稳定实力或预测概率。

### 双对象对比

蓝色为 A，橙色为 B，差异图保留原始单位，每项指标各用独立刻度。可以交换 A/B；选择同一个对象不会生成对比结果。下方可展开原值与差值。指标结构图仅展示双方共同有效维度；归一化参照为当前筛选的同类对象，不把缺失当成零，也不当作绝对能力评级。

### 单局经济时间轴

进入比赛详情，拖动滑块或使用方向键选择真实观测点，查看时间、双方经济和差值；可切换“经济差 / 双方经济”。游标读取原值，线条仅连接已有点；超过 120 秒的缺口断开，观测前后不外推。只有一个点时保留该点，不生成走势判断。

### 对象逐局趋势

对象详情中切换指标，点选一个观测查看原值并进入该比赛。蓝线为逐条记录原值，橙虚线为最近五条记录窗口内的有效均值，显示有效值个数；同一局可能有多次英雄出场，因此这里按记录数计算，不冒称连续五场比赛。缺失位置保留，原值折线在缺失处断开。

### 战队经济节奏矩阵

进入“战队 → 团队复盘”，按行查看比赛，按列查看 2、5、10、15 分钟经济差。方向是本队 − 对手；蓝色领先、橙色落后。超出观测范围或横跨大于 120 秒缺口的时点显示“—”，不是零。相邻可用观测间的检查点可能线性估算，不能当作该秒直接测量。

每列标出有效局数，点比赛回到原始详情。战队顶部汇总跟随日期、对象和来源筛选；“末次观测差”不冒称终局值。翻盘与被翻盘须结合 10 分钟经济差和已知最终赛果，未知赛果不作胜负分类。

## 录入与补录

通道的“BP 录入 / 补录”可以填写双方最多四个禁用、五个选用和一手方。按左右侧与各自手序填写；未知手序保留空位，后面的英雄不会前移。已有比赛打开详情，点击“BP 补录”后单独保存，不需要重传截图或录屏。原始证据保留；保存后刷新 BP 分析。未知赛果不计入手序胜率分母。

“战队名单”支持选择内置 KPL 队名或选择“自定义战队”后填写自己的队名；已保存的自定义队名会作为下拉选项出现，参赛层级可选 KPL、次级联赛、普通战队。内置队名是 2026-06-08 官方公布的夏季赛名单快照，允许自行更名。添加队员时选择默认分路；“身份绑定”也能修改默认分路。身份绑定按每局左右方自动把十人分成两队：只有本队昵称可绑定本队名单，对手昵称单独保留，不会因为同名被并入本队；别名也只作用于本队阵营。手工录入时先确认本队阵营，只有本队五人的身份下拉列出名单，对手行不能关联本队队员。关联队员时，仅在本行分路为空时带入默认值，仍可修改本局实际分路。

手工录入用系统日历选择日期；时长按分钟和秒分别填，或拖动滑杆，点击“留空”恢复未知。资源事件也可拖动时间滑杆并同步分:秒文本。空白页面不会提示恢复；有实际输入但未保存时可以恢复。保存成功后不会再提示恢复同一份已保存草稿。

## 清洗怎么生效

进入“数据清洗”会自动预览。选择去空格、合并重复、异常留空等规则，或修改单元格，页面会自动重新计算；状态栏显示变化数量和错误。按缺失字段排除行属于可选高级规则，用复选框选择必需指标。填写名称后点“保存校正数据集”，生成独立快照，可在“数据集”中用于分析。原始比赛不会被校正数据集覆盖。源数据变更时点击“重新读取来源”重新校对。

身份绑定修订：统计保留原始昵称及真实行数/场次；同局不同出场者不能合并到同一稳定 ID，不同场次的历史昵称允许合并。创建队员会统一提交本页当前选择，避免用旧别名覆盖未保存修改。已有原始比赛不回写；错误绑定由用户核对后修改，不自动猜测纠正。
