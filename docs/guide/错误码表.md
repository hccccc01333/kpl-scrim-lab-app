# 错误码表

错误码一旦发布就不要改语义。界面文案可以调整，码本身保持不变。

| 错误码 | 标题 | 原因 | 用户处置 | 代码位置 | 状态 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| `E-SYS-001` | 工作台连接中断 | 浏览器与主服务 8766 之间的连接断了，常见原因是启动窗口被关掉或服务还没起来。 | 确认启动窗口还在；页面会自动重连，也可以点「立即重试」。打开 /api/health 能看到进程与数据目录。 | `v3/public/app.js · setOffline() / renderOffline()` | 已接入 |
| `E-SYS-002` | 这一页的数据还没返回 | 接口连续失败两次，或静态资源与路由表短暂错配；不是对局数据本身的问题。 | 点「重新读取」；若反复出现，打开 /api/health 并复制诊断信息反馈。 | `v3/public/app.js · load() 失败分支 / renderDataNotice()` | 已接入 |
| `E-MOD-001` | 页面模块加载失败 | 按需加载的页面脚本没有取回来，通常是缓存版本不匹配或文件缺失。 | 按 Ctrl+F5 强制刷新；仍失败时附带诊断信息反馈。 | `v3/public/app.js · ensureModules() / importOnce()` | 预留 |
| `E-CAP-001` | 营地同步失败 | 教练号扫码授权失效、营地接口临时不可用，或该账号没有可拉取的训练赛。 | 重新扫码授权；超过一个月、营地没有详情的老局改走截图 OCR 或录屏新录入。 | `v3/public/capture-page.js · 营地同步` | 预留 |
| `E-CAP-002` | 截图识别结果不完整 | 截图被微信 / QQ 压缩、不是赛后结算页原图，或字段被遮挡。 | 用原图或文件方式重传，逐字段人工校对；不要用猜测补全。 | `v3/public/capture-page.js · 截图 OCR` | 预留 |
| `E-IMP-001` | 表格导入失败 | 模板 sheet 缺失、局序或赛果格式不对、归属赛事未选，或同一局重复导入。 | 按错误行号改好后重新导入；先确认顶栏已选当前赛事。 | `v3/public/official-entry.js · 批量导入` | 预留 |
| `E-EXP-001` | 诊断信息复制失败 | 浏览器拒绝了剪贴板权限，且兜底复制也被拦截。 | 手动选中诊断文本框里的内容复制；反馈时保留错误码即可。 | `v3/public/diagnostics.js · bindDiagnosticCopy()` | 已接入 |
| `E-DOC-001` | 文档内容加载失败 | 生成的 help-content.js 缺失或与文档页版本不匹配。 | 运行 python scripts/build_help_content.py 重新生成；仍失败时反馈诊断信息。 | `v3/public/docs-page.js · helpContent 导入` | 预留 |
